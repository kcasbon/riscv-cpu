# riscv-cpu

This project is an attempt to build a CPU in Logisim Evolution which can execute a large subset of the RISC-V assembly language. Some of th e major components of this CPU are an arithmetic logic unit (ALU), a branch comparator, an immediate generator, a "main memory" (RAM), and, of course, the CPU itself. This CPU also implements a simple 2-stage pipeline, which vastly improves its throughput.
